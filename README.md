# Keerthana S. — Professional Portfolio

A lightweight personal portfolio and engineering blog intended to complement a software engineering resume. Built with static HTML and CSS and hosted on GitHub Pages at https://Keerthu98.github.io/.

## Site sections
- Professional overview and technical focus
- High-level experience summary
- Engineering articles
- Contact and professional links

## Before sharing on a resume
- Replace the LinkedIn homepage link in `index.html` with your actual profile URL.
- Review all experience wording for accuracy and comfort with public disclosure.
- Add only public-safe projects and articles. Do not publish internal architecture, proprietary code, customer details, credentials, or non-public metrics.

## Publishing
This repository is named `Keerthu98.github.io`, so GitHub Pages can serve it at `https://Keerthu98.github.io/`. In repository Settings → Pages, select **Deploy from a branch**, choose `main` and `/(root)`, then save if this is not already configured.

Static HTML/CSS; no build step or paid hosting required.
